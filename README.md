# 🦸 Hero Class Program (Python)

A simple Python program demonstrating **Object-Oriented Programming (OOP)** concepts using a `Hero` class.

This project shows object creation, attributes, methods, and object reference handling.

## 📌 Overview

The program creates a Hero object with details like:

- Name
- Age
- Location
- Number of movies
- Additional properties like mobile number and awards

It also performs actions using class methods.

## ✨ Concepts Covered

✅ Class and Object creation  
✅ Constructor (`__init__`)  
✅ Instance variables  
✅ Updating object values  
✅ Adding new attributes dynamically  
✅ Object reference (`h1`, `h2`, `h3`)  
✅ Calling class methods  

## 🛠️ Technology

- Python 3.x
